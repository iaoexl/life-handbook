# 全民实用常备手册（life-handbook）

[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by/4.0/deed.zh)

> 一套把经典实用手册重构成「可执行笔记」的全民常备库。覆盖生活百科、技能迁移、应急训练、家庭健康与农事经营，把原书内容改造成今天个人与家庭能**照着做**的操作流程与验证标准。
> 
> 本仓库是实用技能与生活知识的整理、汇编与重构，属常识性参考资料。每篇笔记自足、格式统一，打开即用。
